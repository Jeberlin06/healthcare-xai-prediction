# Explainable AI (XAI) Healthcare Risk Prediction Platform

An interactive Explainable AI application designed for clinical decision support. The platform assesses multi-disease risk (Type 2 Diabetes, Coronary Heart Disease, Chronic Kidney Disease) and presents local model interpretability using **SHAP** and **LIME**.

## Key Features
- **Multi-Disease Clinical Assessment:** Interactive forms for Diabetes, Heart Disease, and Kidney Disease risk evaluation.
- **Explainable AI Insights:** Visual feature contribution breakdowns powered by SHAP and LIME.
- **Batch Processing & CSV Upload:** Support for uploading patient batches via CSV with template downloads.
- **Patient Records & Reports:** Dynamic persistent records storage, report generation, and PDF export.

## Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+), FontAwesome
- **Backend / Machine Learning:** Python, FastAPI / Flask, XGBoost, Scikit-learn
- **XAI Libraries:** SHAP, LIME
